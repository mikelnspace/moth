# Mempool Moth 

![Mempool Moth](./mempool-moth.png)

> Guards every transaction too cheap to confirm. Has been waiting since the last halving. Will wait for the next.

An original collectible card, invented in the spirit of the 2016–2018 Counterparty-era Rare Pepe set — hand-drawn style, chaotic crypto in-jokes, scarcity-obsessed lore — but with its own creature, name, and branding. No Pepe the Frog assets or Rare Pepe branding are used; Pepe is Matt Furie's character.

## Concept

The Mempool Moth is drawn to the glow of stuck, low-fee transactions the way real moths are drawn to light. It carries a lantern stitched together from tiny unconfirmed-tx "receipts," and its wing-spots quietly reference the volatility of on-chain fee markets. Built to be sized and styled cleanly enough to inscribe as an Ordinal.
